# Kivi: Viimeinen johtolanka

Interaktiivinen esittelysivu viiden huoneen pakohuone-elämykselle. Sivusto esittelee projektin tarinan, huoneet, pulmat sekä fyysisen toteutuksen tekniset ratkaisut.

## Ominaisuudet

- 60 minuutin esittelyajastin
- Viiden huoneen esittely
- Avattavat haastekuvaukset
- Fyysisen toteutuksen ja elektroniikan esittely
- Kuvamateriaali jokaisesta huoneesta
- Responsiivinen käyttöliittymä
